ЛИНИЯ — CRM студии растяжки
ЗАПУСК НА WINDOWS

1. Щёлкните правой кнопкой мыши по скачанному ZIP-архиву.
   Выберите «Извлечь всё», затем нажмите «Извлечь».

2. Откройте извлечённую папку linia-crm.
   Не запускайте файлы прямо внутри ZIP-архива.

3. Дважды щёлкните по START-WINDOWS.cmd.
   Если Windows скрывает расширения, файл называется START-WINDOWS.

4. Если появится сообщение про Node.js, откроется его официальный сайт.
   Скачайте установщик Node.js версии 24 или новее для Windows (.msi).
   Установите его с обычными настройками.
   После установки закройте окно запуска и снова откройте START-WINDOWS.cmd.

5. При первом запуске дождитесь скачивания компонентов и подготовки интерфейса.
   Нужен интернет. Окно запуска не закрывайте.
   После подготовки CRM сама откроется в браузере.

6. Нажмите «Войти как владелец» для знакомства с CRM.
   В демонстрационной студии уже есть вымышленные клиенты и занятия.

КАК ОСТАНОВИТЬ
Закройте окно запуска, когда закончите работу.
Данные сохраняются в папке data внутри папки проекта.
Не удаляйте эту папку: там находятся данные вашей локальной CRM.

КАК ОТКРЫТЬ СНОВА
Снова дважды щёлкните по START-WINDOWS.cmd.

ЕСЛИ НЕ ПОЛУЧИЛОСЬ
Если порт занят, закройте предыдущее окно запуска CRM.
Если ошибка осталась, скопируйте её текст из окна в чат.

Это локальная демонстрационная версия на вашем компьютере.
Для использования настоящих данных и совместного доступа сотрудников
нужна отдельная настройка рабочей студии. Подробности — в README.md.
